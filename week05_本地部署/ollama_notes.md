# W5 Ollama 部署记录（模板）

## 1. 安装与拉取
- 安装方式：官网下载 OllamaSetup.exe 进行本地安装
- 命令：`ollama pull qwen2.5:0.5b` (实际测试中也尝试了 deepseek-r1:8b)

## 2. 我选的模型与理由
- 模型：qwen2.5:1.5b
- 本机内存：16 GB
- 选择理由：我的本机内存是16GB，根据讲义选型经验（16GB可跑4b量化档），我具备跑稍大模型的条件。但为了保证课堂演示、快速对比实验不卡顿，且0.5b模型体积仅有986python llm.pyMB，速度极快，优先选用 qwen2.5:0.5b 跑通全流程建立手感。（如果后续需要高质量输出，我会再尝试拉取 qwen3:4b 并使用）。*注：前期尝试拉取 deepseek-r1:8b 时因模型体积较大（约5GB）且网络原因下载较慢，故切换为轻量级模型测试。*

## 4. 术语正名
让大模型进小内存靠的是 **量化 (Quantization)**；
**MCP** 另指“模型上下文协议”（第 10 周专讲），不要混用。

## 5. 排错记录
（下载慢 / 内存不足 / 服务未启动 — 各是怎么解决的）
1. **缺少Python依赖库**：在 VS Code 终端运行 `llm.py` 时，报错 `ModuleNotFoundError: No module named 'requests'`。解决方法：在终端输入 `pip install requests` 安装该库后，重新运行代码即可解决。
2. **下载速度慢**：拉取 `deepseek-r1:8b` 时，因模型文件体积较大（约5GB）且服务器在海外，下载极慢。解决方法：通过 `Ctrl + C` 中断下载，转而拉取轻量级的 `qwen2.5:1.5b`（约986MB），实现秒下载、秒响应。
3. **服务未启动/连接失败**：如果 Python 代码报错无法连接到本地接口，排查发现是 Ollama 后台服务未运行。解决方法：检查电脑右下角系统托盘是否有“小羊驼”图标（Ollama服务），若没有则重新启动 Ollama 软件，或使用 `ollama list` 命令验证服务是否正常。
