# 作业1进阶说明：答案附出处

## 实现方式
在 `rag_qa.py` 的 `build_prompt` 函数中，我增加了明确的系统提示词：“请在答案的最后，用【】把参考的原文片段括起来作为出处”。

## 测试效果与发现
**提问**：HSK一级需要掌握多少个汉字？
**RAG回答**：根据资料，HSK一级对应初等一级，需要掌握300个汉字。

**发现与思考**：虽然代码层面已经强制传入了 `ctx` 检索片段并修改了提示词，但由于云端 API 模型的对话习惯（较懒），它有时会省略出处。
*(注：如果使用本地小模型，或者在后续第8周的项目中通过结构化输出约束，可以让出处强制显示。)*
