# 第8周开源项目拆解反思（C 路径）

本周我对照了官方 RAG 教程和 Datawhale 的 llm-universe 开源项目。通过对比发现，我自己写的 `rag_qa.py` 正是标准 2-Step RAG 的雏形。

官方教程中的代码结构更严谨，把数据加载、切分、向量化、存储完全解耦，并且注重使用 LangChain 的标准化接口。这让我深刻理解了“组件可替换”的工程思想：只要接口一致，我可以随时把云端 embeddings 换成本地的 nomic-embed-text，而不需要改动应用逻辑。此外，llm-universe 中关于“系统评估与优化”的章节让我意识到，W7 做的幻觉对照表只是最简单的评估，真实落地还需要用自动化指标来测试检索的准确率和生成的忠实度。

这次对照并没有要求我推倒重来，而是让我明白了自己手写的脚本在工业界标准化框架中的位置，也为我后续把助手升级到 v2.0 指明了方向。
