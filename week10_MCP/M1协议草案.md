# M1 会话协议草案

## 1. 事件类型与字段
每次通信包含以下基本字段：
- `session_id`: 会话唯一标识
- `seq`: 递增序号，用于保证顺序和幂等
- `ts`: 时间戳
- `type`: 事件类型（如 text, tool_call, tool_result 等）
- `payload`: 具体内容负载

## 2. 状态机
主循环状态：`idle → listening → thinking → tool_calling → speaking → idle`
如果用户在 speaking 期间打断，状态机回退到 listening。

## 3. 权威与幂等
- **权威**：服务端是唯一的权威来源，客户端状态以服务端为准。
- **幂等**：服务端根据 `seq` 去重，重复的请求不再执行，直接返回上一次的结果。

## 4. 断线语义
客户端断线重连后，会带上最后收到的 `seq` 请求补发，服务端从该 `seq` 之后的所有消息继续推送，保证消息不丢失。
