# W10 预习作业

## 一、三者辨析（用一句话区分）
1. **Function Calling（模型侧机制）**：大模型在对话中通过输出特定格式（如 JSON），主动向程序“举手”表示需要调用某个外部函数来获取信息。
2. **MCP（工具侧协议）**：一种标准化的通信协议，让不同的 AI 模型能够以一种通用的“插座”方式，连接并调用外部各种现成的工具或数据源。
3. **普通 API 调用**：程序员在代码里预先写死逻辑，不管模型怎么想，程序按固定的顺序去请求接口拿数据，模型不参与“决定何时调用”的过程。

## 二、我希望 MCP 帮我接上的 2 个外部工具
1. **在线语料库（如 BCC 语料库）查询工具**：输入一个词，直接返回真实例句。
2. **在线词典 API**：输入一个词，返回标准的拼音、释义和发音音频链接。
